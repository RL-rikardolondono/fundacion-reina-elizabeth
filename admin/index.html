Configuración inicial (solo la primera vez)

Si todavía nadie tiene usuario, entre una sola vez con la llave de GitHub de esta web y cree los usuarios en la pestaña «Usuarios».

  1. Cree la llave en GitHub con el nombre , sin vencimiento.
  2. En Repository access elija Only select repositories y marque solo .
  3. En Contents elija Read and write y pulse Generate token.
